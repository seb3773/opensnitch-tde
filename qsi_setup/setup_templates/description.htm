Welcome to OpenSnitch TDE Setup

OpenSnitch TDE is a native C++/TQt3 graphical interface for the OpenSnitch application firewall, built specifically for the Trinity Desktop Environment (TDE).

Key Features:

  • Native C++/TQt3 Architecture: Fast startup and minimal memory footprint with zero Python/PyQt dependencies.
  • Real-Time Firewall Interception: Monitor outgoing connections and define granular per-application security rules.
  • Interactive System Tray & Alerts: Real-time desktop popups to allow or block network access instantly.
  • Optimized SQLite Storage: In-memory or WAL-mode statistics, connection logs, and host telemetry.
  • Embedded Assets & Fast DNS: Embedded icons for zero disk latency and integrated native reverse DNS resolution.
